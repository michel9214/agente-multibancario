1 Contexto del Proyecto

Un negocio de agente multibancario en Peru necesita digitalizar el proceso manual de cuadre de caja al finalizar cada turno de operador. Actualmente se realiza con papelitos de POS de cada entidad bancaria, sumando manualmente para verificar que los montos cuadren.

La app automatiza este calculo y almacena evidencia fotografica de cada comprobante, eliminando errores humanos y dejando un registro auditable de cada turno.

Decisiones Confirmadas

  • Moneda: Soles peruanos (S/) — formato S/ 1,234.56
  • Backend: NestJS con Fastify como adaptador HTTP
  • Operadores: 1-3 operadores con gestion multi-usuario y roles (OWNER / OPERATOR) desde el inicio
  • Mejoras incluidas: Modo offline basico, exportar PDF/Excel, dashboard con graficos

5 Formula de Cuadre

El calculo de cuadre compara los totales de cierre contra los totales de apertura, restando los movimientos netos realizados durante el turno. Si la discrepancia es cero, el turno esta cuadrado.

Calculo principal

discrepancia = (saldos_cierre + efectivo_cierre) - (saldos_apertura + efectivo_apertura) - movimientos_netos
movimientos_netos = SUM(entradas) - SUM(salidas)
Resultado = 0: El turno esta CUADRADO. Todos los montos coinciden correctamente.
Resultado ≠ 0: Existe un DESCUADRE. Se muestra el monto de diferencia para investigacion.

6 API Endpoints

API RESTful con autenticacion JWT. Documentacion auto-generada con Swagger en /api/docs.

Metodo Ruta Descripcion
POST /api/auth/login Login → retorna JWT
POST /api/auth/register Crear usuario (solo dueno)
GET POST /api/entities Listar / Crear entidades bancarias
POST /api/shifts Abrir turno
GET /api/shifts/active Turno activo del operador
PATCH /api/shifts/:id/close Cerrar turno + calcular cuadre
POST /api/shifts/:id/movements Registrar movimiento en el turno
GET /api/shifts/:id/reconciliation Resultado del cuadre
POST /api/uploads/receipt Subir foto de comprobante

7 Pantallas de la App

La aplicacion Flutter consta de 8 pantallas principales que cubren el flujo completo desde el inicio de sesion hasta la revision del historial.

  • 1
    Login Email + contrasena
  • 2
    Dashboard Estado del turno, boton “Iniciar Turno”
  • 3
    Iniciar Turno Wizard de 3 pasos (efectivo + saldos por entidad)
  • 4
    Turno Activo Lista de movimientos del turno en curso
  • 5
    Agregar Movimiento Tipo, monto, direccion, descripcion, foto
  • 6
    Cerrar Turno Wizard de 3 pasos (efectivo + saldos cierre)
  • 7
    Resumen de Cuadre Resultado: CUADRADO o DESCUADRE
  • 8
    Historial Lista de turnos cerrados con filtros
